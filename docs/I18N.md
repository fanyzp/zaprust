# Internationalization

Zaprust's interface strings live in locale files so the UI can be
translated without touching draw code.

## Layout

- `crates/app/locales/en.toml`, English, the source locale. It is
  complete: every key the code looks up exists here.
- `crates/app/locales/id.toml`, Indonesian, a starter locale. It
  translates a subset; everything else falls back to English at
  runtime.
- Lookup code: `crates/app/src/i18n.rs` (`t()` for plain strings,
  `tf()` for one named placeholder).

## Keys

- One flat map per file; keys are quoted dotted paths grouped by
  screen: `settings.appearance.title`, `conversation.typing`, …
- Keys are stable API: renaming a key means updating every locale
  and every call site.
- Values may contain named placeholders: `"Group · {count} members"`.
  Every translation of a key must keep exactly the same
  placeholders; a test enforces this.

## Adding a language

1. Copy `en.toml` to `locales/<code>.toml` (use the ISO 639-1
   code, e.g. `es.toml`).
2. Translate the values. You can translate a subset, untranslated
   keys fall back to English, but keys present in your file must
   exist in `en.toml`.
3. Add the per-locale `*_map()` accessor next to the existing ones and register the file in `i18n.rs`: an `include_str!`, a `map_for`
   arm, and an entry in `LOCALES` (the Settings picker reads it).
4. Run `cargo test -p app i18n`: parsing, subset, and placeholder
   checks must pass.

## Rules for new UI strings

- Never hardcode a user-facing string in draw code; add the key to
  `en.toml` first, then call `t("…")`.
- English copy follows the project rules: plain language, sentence
  case, no developer jargon.
- Demo conversation content is data, not UI copy, and is not
  localized. The debug inspector is a developer surface and stays
  English by design.

## Current coverage

Converted surfaces: the settings shell and its pages, the chat
list chrome, the conversation header and its menu, the crash
banner, the profile panel, notices, and the message surfaces.
The locale files (en, id) carry the same key set; the parity
test in the app crate fails the build when they drift. The
fallback design means a partial conversion never breaks another
locale. (An earlier draft of this page described plugin and
AI-agent surfaces; those features were removed from the app
and the description with them.)
